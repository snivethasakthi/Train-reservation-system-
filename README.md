# Mukaya Rail – Train Reservation System

## Project Overview

Mukaya Rail is a UI/UX design project focused on making the train reservation process simple and user-friendly.

## Project Type

UI/UX Design

## Design Tool

Figma

## Project Objective

To design a user-friendly interface that helps users explore train reservation features through clear screens and easy navigation.

## Key Screens

* Login and Registration
* Train Search
* Train Details
* Seat Selection
* Passenger Details
* Booking Confirmation

## Features

* Simple and clean user interface
* Easy navigation
* User-friendly booking flow
* Consistent visual design
